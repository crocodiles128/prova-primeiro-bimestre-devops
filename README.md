# API de Reservas TechNova

Projeto da Prova do 1º Bimestre de DevOps (UniFAAT).

## Objetivo

Este repositório organiza a base inicial do projeto, preparando a estrutura para o desenvolvimento da API de reservas, documentação e infraestrutura sem implementar código funcional nas fases iniciais.

## Estrutura do projeto

- `app/` - aplicação da API
- `docs/` - documentação complementar
- `infra/backend/` - backend de infraestrutura
- `infra/modules/network/` - módulo de rede
- `infra/modules/security/` - módulo de segurança
- `infra/modules/compute/` - módulo de computação
- `infra/modules/database/` - módulo de banco de dados

## Observações

- Esta é a base inicial da Fase 1.
- Ainda não há implementação de Docker, Terraform ou código funcional da API.
- O arquivo `.env.example` serve como template de variáveis locais.
